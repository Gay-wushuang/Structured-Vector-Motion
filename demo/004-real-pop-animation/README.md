# Real POP Authored Animation Demo 004

This seven-second demo starts from the frozen real Primitive Operation Painter
runner capture, not hand-authored ellipse/rectangle construction. The builder
reimports the exact prefix and 1,296 raw tokens, runs the existing POP Adapter,
accepts its Proposal, and asserts the recorded Golden P Revision identity.

The resulting 143 editable POP primitives retain their Entity, Operation, and
Render Stack identities. Three explicit, unlabeled spatial composition Groups
are then added for authoring; Group, Style, and Camera Tracks animate the
accepted scene. No Eye/Hair/Face labels, new inference, model rerun, NPA,
correspondence, or recovery behavior is introduced.

```powershell
python demo/004-real-pop-animation/build_demo.py
```

Full frame sequences are ignored build outputs. Git retains the resulting SVM
Document, MP4, builder, and five representative frames.
