## 1. 两种规格与交付证据

| 项目 | A · 固定 CI 测试素材 | B · SVM Motion 正式演示 |
| --- | --- | --- |
| 场景标识 | `synthetic-controlled` | `svm-motion-controlled` |
| 来源 | 受控程序合成。固定相机、一个运动目标、可验证的静态背景。 | 真实、可校验的 SVM Document。沿用受控修复域并披露离线注入的退化。 |
| 时长 | 恰好 2 秒 | 5–10 秒，含两端 |
| 帧率和帧数 | 恒定 `12/1` fps，24 帧，索引 `0..23` | 优先恒定 `12/1` fps，60–120 帧。由批准的时长和帧率计算。 |
| 分辨率 | 恰好 256 × 256 | 优先 256 × 256。先按原场景宽高比等比适配并记录背景和边距。 |
| 无损帧 | RGB8 PNG，sRGB 样本值，无 alpha | 同左，连续、同尺寸、按展示顺序编号 |
| 所需证据 | S1–S5 开发校准、H1–H5 冻结留出验收、无退化保护对照 | Document/Revision 来源、FINAL 且当前的 SVG 序列、光栅化证据、整段前后输出、同步对照与验收报告 |

**A 的通过仅支持固定合成素材的受控结论。B 必须单独交付和验证。** 两种规格均属受控实验，不得宣称自然视频泛化。Manifest 和报告均记录 `scenario_kind`、`real_video: false` 和 `generalization_claimed: false`。

B 使用 `MotionEvaluator.evaluate(tick, quality=FINAL)`，在同一身份的只读 Document 或 Revision 快照上连续采样。失败、阻塞、缺帧、stale 或低于 FINAL 的结果使源序列失败。用 `SVGRenderer` 输出每帧 SVG，由 Core 外的固定版本光栅化工具生成 RGB8 PNG。记录 Document 文件 SHA、可用的 Revision ID、SVM 代码 SHA、每帧整数 Motion tick、求值质量、SVG/PNG 摘要、画布与光栅化配置。干净生成来源证据保存在离线侧，repair 仅接收退化帧及其元数据。

A 的第 `i` 帧覆盖 `[i/12, (i+1)/12)` 秒，`tick(i)=i`，最后一帧 PTS 为 `23/12`。B 使用同样的左闭右开规则，画面 PTS 从 0 开始。以 6 秒、Document Timebase 24 ticks/s、12 fps 为例，选 `[0,144)`，按 `0,2,...,142` 采样 72 帧。源 Timebase 必须与选定采样率精确兼容，禁止隐式舍入、丢帧或补帧。若选用既有 960 × 540 的 16:9 Motion 示例，256 × 256 画布内可先试 256 × 144 等比成像。若边缘或掩膜在缩放后难以辨认，向策划线提交等比偶数尺寸方案（如 320 × 180）、SVM Timebase 与 fps 的整数映射和对应帧数，批准后记录到演示 profile。A 规格保持固定。

## 2. 功能范围

| ID | 需求 | 支持边界 |
| --- | --- | --- |
| CVR-F-01/02 | 接收并验证规范 PNG 帧包。受限 MP4 可显式摄取，原始媒体字节及源展示时间可追回。 | 固定规格 A 或经批准的 B；原视频、帧、掩膜和配置只读。MP4 解码规则由[管线契约](pipeline-contract-v0.1.md)定义。 |
| CVR-F-03 | 披露 ROI 和显式掩膜。 | 半开整数矩形，二值掩膜。写入授权、供体可靠性、静态采样和评分掩膜各有明确用途。 |
| CVR-F-04 | 修复局部遮损或缺陷。 | 依据同一静态背景位置的至少两次可靠观测，保护移动物体。证据不足保留像素并标记 `UNRESOLVED`。 |
| CVR-F-05 | 抑制闪烁。 | 使用退化序列内显式静态采样的有界整数加性亮度校正，绝对偏移上限 32 DN，禁止静默截断估计。 |
| CVR-F-06 | 改善短暂拖影。 | 显式拖影区域与运动物体分离，至少有两次无拖影的可靠背景观测。超域或证据不可信时拒绝或按契约弃权。 |
| CVR-F-07 | 稳定外观。 | 同一修复授权下可启用有界逐通道整数修正，绝对上限 16 DN。固定目标内部参考残差、空间误差和运动边缘均需评分。 |
| CVR-F-08/09 | 保留无损前后帧，导出三支可播放同步 MP4，并交付可独立检查的记录。 | `before.mp4` 为退化输入，`after.mp4` 为修复结果，`comparison.mp4` 同 PTS 左前右后。必交 `run-manifest.json`、`metrics.json`、`acceptance-report.json`。 |
| CVR-F-10 | 复用 Motion/SVG 作为正式演示源。 | 光栅化、退化生成、修复、编码、评分均在 Core 外。保持 [SVM 边界](integration-boundary.md)。 |

局部填补与去拖影的移动物体内部仍属超域。已声明光度范围内的有界亮度/颜色校正可作用于通过该范围的物体。无法辨别内容固有变化和退化时，应弃权。自然视频、自动跟踪/掩膜、移动相机、通用遮挡恢复、从未观测细节合成、空间 fallback、光流、神经模型和 SVM 可编辑恢复不在本轮范围。

## 3. 授权、隔离和交付语义

- 原媒体和输入快照可追回且 SHA 可校验。所有生成物写入新位置。读取源和写入结果之间禁止覆盖、重命名或删除原件。
- 干净参考和注入真值属于离线样例构造与评分。repair 进程只获得退化帧、时间、显式授权与可靠性掩膜及版本化配置。禁止读取、接收、哈希或通过其他输入间接获取参考、注入参数、真实运动或评分结果。
- 记录掩膜用途、来源、摘要、每帧支持面积和坐标。羽化参数只扩展保护域的检查范围，写入仍需明确授权。无损 PNG 的保护域外像素必须与退化输入完全相同。
- 每项产物可追溯到输入 SHA、配置 SHA 和实际代码 SHA。便携清单仅用包内相对路径或角色及 SHA，工具参数记录可复现语义。失败或中断不得留下本次运行的 `SUCCESS`。
- 修复质量以无损 PNG 独立计分。MP4 单独验证媒体属性和逐 PTS 内容。使用同一固定工具环境重复验证规范像素和语义记录，平台间媒体比较依赖已审核的解码门槛。
